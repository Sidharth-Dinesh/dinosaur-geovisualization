# Dinosaur Atlas

Open `index.html` in a browser. An internet connection is needed for the two D3 libraries; the map and dinosaur data are included locally and embedded in `js/data.js`, so no server is needed.

Drag across the timeline to select a time range. Drag the selection to move it, or its edges to resize it. Hover over map points for details. Use Reset selection to show all records. Focus view hides the masthead and footer for screenshots.

The original dataset, Patterson projection, group color mapping, timeline curve, point sizing and animated filtering are retained. Course headings, personal contact details and assignment explanations have been removed. Hover handling, record identity, responsive brushing and clearing the selection are repaired. All records are visible initially.

Locations use the original present-day country coordinates; this is not a reconstruction of ancient continents. Overlapping records share coordinates.
